# Roadmap

This roadmap is revised through public RFCs.

## Phase 0: Approval and formation

- [x] Approve the project name, mission, scope, and disclaimer.
- [x] Approve code, data, and documentation licenses.
- [x] Create the GitHub organization and repository.
- Select the initial maintainers and public contact channel.
- [x] Review RFC 0001.

## Phase 1: Foundation

- [x] Select TypeScript and Fastify for the first implementation.
- [x] Define API and error schemas.
- [x] Add automated type checks, tests, builds, and dependency auditing.
- [x] Add OpenAPI generation.
- [x] Add source manifests and reproducible pipeline conventions.
- [x] Approve the first official-source administrative-regions dataset.

## Phase 2: Version 0.1

- [x] Implement region endpoints locally.
- Publish province and prefecture endpoints.
- Publish commune endpoints.
- [x] Add multilingual region search.
- [x] Add provenance, freshness, and health metadata.
- [x] Add the approved adapted regions database in JSON format.

## Phase 3: Community preview

- Deploy a public preview with rate limits.
- Publish contribution tasks and `good first issue` labels.
- Run the first community review session.
- Document uptime expectations and known limitations.
- Submit MoroccoAPI to relevant Moroccan open-source directories.

## Later candidates

Subject to separate source and license reviews:

- Public educational institutions.
- Public healthcare facilities.
- Selected official economic indicators.
- Public-service locations.

Real-time financial-market redistribution, personal-data lookup, and sources without clear redistribution rights are excluded.
